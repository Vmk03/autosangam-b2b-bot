# 🛺 AutoSangam B2B Telegram Bot (ஆட்டோ சங்கம் B2B டெலிகிராம் பாட்)

இந்த பாட் ஓட்டுநர்கள் டெலிகிராம் மூலமாக வாய்ஸ் மெசேஜ் (Audio) மற்றும் வாடிக்கையாளர் மொபைல் எண் அனுப்பி எளிதாக **B2B வாடகை** போட உதவுகிறது.

---

## 📌 முக்கிய அம்சங்கள் (Key Features)
1. **100% B2B மட்டும்:** கஸ்டமர் ஆப் (Customer App) வாடகைகள் மற்றும் வாட்ஸ்அப் (WhatsApp) வாடகைகள் எதிலும் எந்தக் குறுக்கீடும் இல்லாமல், இது முழுக்க முழுக்க டிரைவர்-டூ-டிரைவர் B2B-க்காக மட்டுமே இயங்கும்.
2. **டிரைவர் சரிபார்ப்பு (Driver Authentication):** ஆட்டோ சங்கம் ஆப்பில் அட்மினால் அங்கீகரிக்கப்பட்ட (`approved`) ஓட்டுநர்கள் மட்டுமே இந்த பாட்டைப் பயன்படுத்த முடியும்.
3. **Cloudinary ஆடியோ அப்லோட்:** ஆடியோக்கள் உங்கள் `dz8gefmjd` Cloudinary கணக்கில் தானாகவே பதிவேற்றப்படும்.
4. **தானியங்கி ஆடியோ அழிப்பு (Auto-Cleanup):** காலாவதியான வாடகைகளின் ஆடியோ ஃபைல்கள் Cloudinary-ல் இருந்தும் Firestore-ல் இருந்தும் தானாகவே (ஒவ்வொரு 30 நிமிடத்திற்கும் ஒருமுறை) அழிக்கப்படும்! அட்மின் மேனுவலாக பட்டன் அழுத்த வேண்டியதில்லை.

## 🚀 பாட்டை தொடங்குவது எப்படி? (Quick Setup)

### படி 1: டெலிகிராம் பாட் டோக்கன் பெறுவது (Get Bot Token)
1. உங்கள் போனில் அல்லது கணினியில் Telegram-ஐ திறந்து **`@BotFather`** என தேடவும் (Official Blue Tick இருக்கும்).
2. `/newbot` என தட்டச்சு செய்து அனுப்பவும்.
3. பாட்டின் பெயர் கேட்கும்: (எ.கா: `AutoSangam B2B`)
4. பாட்டின் யூசர்நேம் கேட்கும்: (எ.கா: `autosangam_b2b_bot`)
5. BotFather உங்களுக்கு ஒரு **HTTP API Token** தருவார் (எ.கா: `7823456789:AAH...`).

### படி 2: டோக்கனை `.env` ஃபைலில் சேர்ப்பது
இந்த ஃபோல்டரில் உள்ள `.env` ஃபைலைத் திறந்து:
```env
TELEGRAM_BOT_TOKEN=உங்கள்_பாட்_டோக்கன்_இங்கே
```
என்று பேஸ்ட் செய்து சேமிக்கவும் (Save).

### படி 3: பாட்டை இயக்குவது
`run_bot.bat` ஃபைலை டபுள் கிளிக் (Double Click) செய்யவும்!
அல்லது டெர்மினலில்:
```bash
npm start
```

1. Telegram-ல் பாட்டைத் திறந்து **`/start`** கொடுப்பார்கள்.
2. **"📱 எனது ஓட்டுநர் எண்ணை பகிர்க"** பட்டனை அழுத்துவார்கள்.
3. கணக்கு சரிபார்க்கப்பட்டுவிட்டால்:
   - ஒரு **வாய்ஸ் மெசேஜ் (Audio)** அனுப்புவார்கள்.
   - வாடிக்கையாளரின் **10 இலக்க மொபைல் எண்ணை** அனுப்புவார்கள்.
4. உடனே ஆட்டோ சங்கம் டிரைவர் ஆப்பில் உள்ள B2B கார்டில் ஆடியோ ஒலியுடன் புதிய வாடகையாகத் தோன்றும்! 🛺
